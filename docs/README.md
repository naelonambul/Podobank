# Supporting Documentation

`docs/` contains long-lived supporting, reference, research, architecture, decision-history, and historical material.

It is not the active SDLC authority.

When documentation conflicts with the human owner's explicit decision, `AGENTS.md`, the root baseline, or an approved change packet, stop and surface the conflict rather than treating `docs/` as an override.

Create subdirectories such as `architecture/`, `decisions/`, `research/`, or `history/` only when the project has real content for them.
