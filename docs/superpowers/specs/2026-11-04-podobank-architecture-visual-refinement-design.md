# 포도뱅크 시스템 아키텍처 다이어그램 시각 정리

## 의도

README에서 보이는 시스템 구조도는 Cloudflare 영역의 큰 색면이 시선을 많이 차지하고, OCI의 실행 프로그램들은 글자 배지로만 구분됩니다. 경계와 프로그램을 더 빠르게 알아볼 수 있게 정리합니다.

## 목표

- Cloudflare Edge의 넓은 배경 패널을 얇은 세로 경계선으로 줄입니다.
- UI Worker→VPC Service와 API Worker→VPC Service를 각각 좁은 이중 윤곽 그룹으로 묶습니다.
- OCI의 Nginx, FastAPI, MariaDB, MongoDB, Grafana Alloy, Loki, Prometheus, Grafana 카드에 해당 프로젝트의 공식 로고를 넣습니다.
- 카드 이름, 포트, 데이터 설명, 요청·금융·관측 화살표를 유지합니다.
- 로고는 저장소에 로컬 파일로 보관해 렌더링 시 외부 네트워크에 의존하지 않게 합니다.

## 비목표와 제약

- 실제 서비스 토폴로지, 주소, 포트, 데이터 흐름, 보안 경계는 바꾸지 않습니다.
- 새 프로그램, 외부 폰트, 렌더링 의존성을 추가하지 않습니다.
- 공식 로고를 변형하거나 비율을 왜곡하지 않습니다. 각 로고의 원 출처와 사용 안내를 함께 기록합니다.
- 로고가 작은 크기에서 읽히지 않는 경우에도 텍스트 이름을 남겨 의미를 전달합니다.

## 검토한 방향

- **A — 기존 패널 축소:** 현재 Cloudflare 배경을 유지하고 내부 카드의 폭과 높이만 줄입니다. 적용이 단순하지만 Cloudflare 영역이 여전히 별도 대형 구역처럼 보일 수 있습니다.
- **B — 얇은 경계와 짝 카드 (선택):** Cloudflare 배경 패널을 얇은 세로 경계로 바꾸고, UI 및 API 경로를 각각 이중 윤곽의 좁은 그룹으로 표현합니다. 오른쪽 OCI 프로그램 카드에는 각 제품의 공식 로고를 넣고 이름과 설명을 그대로 둡니다. 영역을 압축하면서도 Worker→VPC 연결과 실행 프로그램을 구분하기 쉽습니다.

## 성공 기준

1. Cloudflare가 넓은 배경 블록 대신 얇은 경계로 보입니다.
2. UI와 API의 Worker→VPC 경로가 각각 한 쌍으로 명확하고 기존 화살표 방향이 유지됩니다.
3. OCI 서비스 카드에서 공식 로고와 텍스트 이름을 함께 확인할 수 있습니다.
4. README 미리보기의 전체 흐름과 기존 설명이 잘리지 않습니다.
5. HTML 원본과 갱신된 PNG가 함께 제공되고, 로고 출처·사용 안내가 저장소에서 확인됩니다.
