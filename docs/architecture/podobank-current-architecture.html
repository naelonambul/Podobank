흐름부터 살펴보기

파란색은 브라우저 요청, 초록색은 금융 데이터와 이벤트, 보라색은 로그·지표와 Grafana가 읽는 조회 데이터입니다. 관측 화살표는 데이터를 받는 저장소와 대시보드 방향으로 향하며 Grafana는 로그나 지표를 쓰지 않습니다. 구성요소를 선택하면 역할과 설정 출처가 여기에 표시됩니다.

노드를 클릭하거나 키보드로 선택하세요.

개발 프리뷰 안내

공개 Worker 주소를 사용하는 합성 데이터 개발 환경입니다. 운영 은행 구조나 고가용성 배포를 뜻하지 않습니다. MongoDB 이벤트는 MariaDB commit 뒤 API가 한 번 시도하며, 기록 실패 시 유실될 수 있습니다. JSONL 관측 흐름은 MongoDB 이벤트 저장과 독립되어 있습니다.
